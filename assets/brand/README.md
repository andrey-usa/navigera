# Brand

The Route wordmark: the N is a plotted course, an open origin below the
line and an orange destination on top; the rest is Poppins Medium, drawn
as outlines (no font needed).

| file | use |
|---|---|
| `wordmark.svg` | on light backgrounds |
| `wordmark-dark.svg` | on dark backgrounds |
| `mark.svg` | the N alone: favicon, small sizes |
| `social-card.png` | link previews, 1280 x 640: upload it under the repository's Settings, Social preview |
| `../../skills/.claude-plugin/icon.png` | the N on its tile: app and plugin icon |

Teal `#03787E`, signal `#EE6C3E`, ink `#0E2A30`, tile `#F0EEE6`.
