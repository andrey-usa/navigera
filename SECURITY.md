# Security policy

navigera drives a real browser and, in session mode, exposes it on a local
socket (a Unix socket, or on Windows a loopback TCP port guarded by a random
token). Reports about anything that lets another user, process or web page
reach that socket, the browser or its profile are especially welcome.

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/andrey-usa/navigera/security/advisories/new)
rather than a public issue. Only the latest release receives fixes.
