# Browser-driver ladder

Head-to-head benchmark of CDP browser drivers on one scripted session,
run in CI (`.github/workflows/bench.yml`) on identical hardware.

## Contenders

| contender | driver | runtime |
|---|---|---|
| `nv-serve` | `navigera serve` — this repo (navigera + Chrome) | native, no Node |
| `playwright` | `playwright-core`, `channel: 'chrome'` | Node |
| `puppeteer` | `puppeteer-core`, system Chrome | Node |
| `chromiumoxide` | `chromiumoxide` 0.7 (bench-only crate in `contenders/`) | native Rust |
| `chromedp` | `chromedp` v0.19.1 (bench-only module in `contenders/`) | native Go |
| `gorod` | `go-rod` v0.116.2 (bench-only module in `contenders/`) | native Go |

All six drive the **same headless Chrome** (`--headless=new`) over the
**same fixture pages** (deterministic, generated by `gen_fixtures.py`,
served from 127.0.0.1 — no network weather, no bot walls).

One per-driver note: `go-rod`'s `Page.Eval` wraps the JS as
`function() { return (JS).apply(this, arguments) }`, so it invokes a bare
function expression itself — an explicit IIFE would break there (its
non-function result has no `.apply`). `gorod` therefore uses bare arrows,
which rod deterministically invokes; every other contender uses explicit
IIFEs for the same guarantee.

## The session (identical for every contender)

1. launch → 2. goto listing page → 3. eval title → 4. eval card count →
5. eval extract 500 cards as JSON → 6. fill search box → 7. click search →
8. eval visible-card count → 9. screenshot → 10. new tab → goto detail page →
11. eval title + row count → 12. close.

Plus two micros: **warm eval round-trip** (200× `() => document.title`) and
**cold start** (launch → new page → one eval → close).

## Accounting

* **wall** — best of N, `perf_counter` around the run.
* **driver CPU / peak RSS** — exact, `os.wait4` on the driver process itself
  (the `navigera` binary for `nv-serve`, node for the JS contenders).
* **chrome CPU / peak RSS** — sampled from `/proc` every 50 ms over the
  chrome process tree; approximate, marked `*`.
* **correctness** — every contender must produce identical normalized
  `extract_a.json` and identical counts (titles, card counts, filter result,
  row count); the ladder fails otherwise.

## Run it

```text
# from the repo root
python3 bench/ladder/gen_fixtures.py
cargo build --release --bin navigera
cargo build --release --manifest-path bench/ladder/contenders/chromiumoxide/Cargo.toml
cd bench/ladder/contenders/chromedp && go mod tidy && go build -o ladder-chromedp . && cd ../..
cd bench/ladder/contenders/gorod && go mod tidy && go build -o ladder-gorod . && cd ../..
cd bench/ladder && npm install
NAVIGERA=$PWD/../../target/release/navigera \
CHROME_BIN=$(which google-chrome) \
python3 ../ladder/ladder.py --out-dir out
```
